SKYHAMMER / WRAITH GEAR — 0.2 단일 장비 세트 시제품
제작일: 2026-10-05

실제 게임용 3D 장비 세트입니다. 참고 사진이나 Brita 모델/텍스처를 복제하지 않고
새 지오메트리와 팔레트 텍스처를 제작했습니다. 바닐라 골격의 바인드 행렬을
호환 기준으로 사용합니다. Brita, Bandits, Viewpoint 없이 장비 자체를 로드할 수 있습니다.

구성: 아이템 하나, 의상 XML 하나, 스키닝 모델 하나
WraithGear.OperatorSet — 레이스 특수부대 장비 세트
전술 헬멧 + 내려진 4안 야투경 + 헤드셋/마이크 + 얼굴 가리개 + 방탄복/파우치.
분리 장비 세 개를 착용하는 방식에서 단일 장비 착용 방식으로 변경했습니다.
머리/목/상부 몸통/하부 몸통의 네 본에 연결되어 각 부위가 따로 움직입니다.

총 3,432 triangles. 다섯 명 모두 착용 시 장비 지오메트리 합계 17,160 triangles.
이는 FPS 보장이 아니며 캐릭터와 무기 등의 폴리곤은 포함하지 않은 수치입니다.
현재 Wraith의 남성 대원을 기준으로 제작했습니다. 여성 착용 전용 피팅은 미검증입니다.
NVG는 장식이며 시야 밝기나 AI 탐지 능력을 바꾸지 않습니다.
아이콘은 게임 기본 아이콘을 임시로 참조합니다. 별도 바닥 드롭 모델은 아직 없습니다.
전용 전투복/바지/장갑/부츠는 포함하지 않으며 기본 SWAT 전투복과 조합합니다.

파일
- SkyhammerWraithGear/: Build 42.21 테스트용 독립 모드
- assets/Wraith_Gear.obj + .mtl: 다른 3D 편집기에서 편집 가능한 원본 장비
- build_gear.py: 재생성 가능한 모델/의상 데이터 제작 소스
- wraith-gear-*.png: 실제 제작 지오메트리의 외부 렌더, 게임 스크린샷이 아님
- integration/: 클로드가 기존 Wraith에 연결할 수 있는 의상 데이터와 설명

테스트 설치
SkyhammerWraithGear 폴더를 C:\Users\user\Zomboid\mods 에 복사한 후
테스트 세이브에서 Skyhammer - Wraith Gear Prototype을 활성화합니다.
디버그 아이템 목록에서 WraithGear 또는 Wraith 이름으로 검색해 세트 하나를 착용합니다.
별도의 헬멧/야투경/마스크/방탄복은 벗겨 중복 렌더링을 피합니다.
기존 0.1 테스트 ZIP은 세 개의 분리 장비인 이전 버전입니다. 0.2 ZIP을 사용하십시오.
패키지 제작 작업은 실제 설치 폴더/로드 순서/기존 Wraith 코드에 변경을 가하지 않았습니다.

검증 범위
- 설치된 PZ의 jassimp64.dll과 .x 로더와 동일한 후처리 옵션으로 통합 모델 임포트 성공
- PZ ProcessedAiScene에서 네 본을 쓰는 스키닝 모델 변환 성공
- 노멀, UV, 삼각형, 본 이름, 모든 버텍스 스키닝 가중치 합 검사 통과
- 의상 XML / 아이템 ID / 텍스처 경로 / 한영 번역 참조 검사 통과
- 외부 OpenGL 렌더 4방향 확인

남은 인게임 확인
실제 세이브를 실행한 착용 검증은 하지 않았습니다. 조준, 걷기, 달리기, 앉기 중
턱/목/어깨와 SWAT 복장의 관통 여부, 2D와 3D 시점, 다른 머리 모양의 숨김,
Bandits 소환 후 외형 적용을 확인한 다음 배포용으로 확정해야 합니다.
헬멧은 머리 본에 고정, 마스크 밑단은 목과 머리에 가중치를 나누고,
방탄복은 몸통 두 본에 연결했습니다. 이 세트의 방어 수치는 몸통 방탄복 기준이며
머리까지 무적/방어 효과를 추가하는 아이템은 아닙니다.

재생성은 build_gear.py → prepare_preview.py → render.py 순서입니다.
제작 도구와 Java 검증/렌더 클래스는 게임 배포 ZIP에 포함하지 않습니다.
